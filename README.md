# taskline
Консольный менеджер личных задач. Задачи хранятся в одном текстовом файле,
работа идёт через команды терминала — без базы данных, аккаунтов и синхронизации.
Подойдёт, если вы живёте в терминале и хотите записывать дела там же,
не переключаясь в браузер или отдельное приложение. Рассчитан на одного
пользователя на одной машине.

## Возможности
- Добавление, просмотр и закрытие задач
- Хранение в обычном текстовом файле — можно читать и править вручную
- Работает офлайн, без регистрации
- Не требует прав администратора

## Требования

- Python 3.9 или новее
- ОС: Linux, macOS, Windows
- Около 2 МБ свободного места

> Важно: нужен именно Python 3.9+. На 3.8 команда `python -m taskline --version`
> завершится ошибкой синтаксиса.

## Установка

1. Клонируйте репозиторий:

   ```
   git clone https://github.com/example/taskline.git
   cd taskline
   ```

2. Создайте виртуальное окружение и активируйте его:

   ```
   python -m venv venv
   source venv/bin/activate
   ```

   В Windows вместо последней команды: `venv\Scripts\activate`

3. Установите зависимости:

   ```
   pip install -r requirements.txt
   ```

4. Проверьте, что всё работает:

   ```
   python -m taskline --version
   ```

   Ожидаемый вывод: `taskline 1.0.0`

## Пример использования

Добавить задачу:

```
taskline add "Сдать отчёт по практике"
```

Посмотреть список:

```
taskline list
```

Вывод:

```
[1] Сдать отчёт по практике
[2] Купить билеты
```

Отметить задачу выполненной:

```
taskline done 1
```

Файл с задачами лежит в `~/.taskline/tasks.txt`.
